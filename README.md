# PowerShell Customization

Configurazione pubblica e riutilizzabile per personalizzare PowerShell 7 e Windows Terminal.

Il repository raccoglie solo componenti generici e condivisibili: temi, profili PowerShell, configurazione terminale e feature opzionali. Credenziali, host SSH, endpoint aziendali, namespace, nomi di servizi e percorsi personali devono restare fuori dal repository.

Le personalizzazioni specifiche del singolo PC vanno mantenute in file locali non versionati.
